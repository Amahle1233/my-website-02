# Team Clothing and Gifts - WEDE5020 POE Part 3
Durban uniform and promotional goods supplier website (HTML, CSS, JavaScript).

## Features (Part 3)
- Services: JS-rendered product cards with search, category filter, sort, lightbox, FAQ accordion
- Contact: validated form that compiles an email (`mailto:`) + Leaflet/OpenStreetMap map with marker
- Enquiry: validated form, AJAX submit (`fetch`), instant cost estimate, lead time and bulk discount
- Mobile menu toggle, CSS entrance animation, dynamic footer year
- SEO: unique titles, meta descriptions, one H1 per page, alt text, internal links, lazy images

## How to run
Open `index.html` in a browser (no build step).
